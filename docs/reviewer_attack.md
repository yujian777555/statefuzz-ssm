# 审稿人攻击清单

## 当前支持的主张

在结构化重复的远程记忆压力条件下，Mamba-130M 的循环状态内容会因果影响远程记忆行为。

## 明确不主张

- 不声称所有 SSM 都具有相同机制。
- 不声称存在普适记忆长度边界。
- 不声称所有长上下文失败都由循环状态造成。

## 可能质疑与证据

| 质疑 | 回应证据 |
| --- | --- |
| 结果只是任意 cache 扰动 | 红/蓝正确状态恢复 8/8，随机状态 0/8，错误状态 0/8。 |
| 只对 red/blue 有效 | 预声明 cat/dog；正确状态 8/8、错误状态 0/8、随机状态 5/8，显示状态内容特异性。 |
| cat/dog 没有失败，不能算恢复复制 | 已明确将 cat/dog 仅作为机制支持，不作为失败恢复证据。 |
| 可能是单模型特例 | 论文声明限定为 Mamba-130M；Mamba2 和另一 SSM 被列为未来独立验证。 |
| 统计不可复现 | 仓库保留固定模板、种子、token 计数、干预模式、结果 JSON 和测试命令。 |
| CUDA 快速路径差异影响结果 | 明确记录使用 Transformers 顺序实现，未宣称快速 kernel 性能或等价性。 |
