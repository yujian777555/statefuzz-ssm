# 相关工作

本轮稿件严格受冻结证据范围约束，没有执行外部文献检索，因此本节只建立待后续文献轮次填充的概念位置，不声称完成优先权或新颖性核查。正式投稿前，需要围绕长上下文评测、状态空间模型鲁棒性、神经网络模糊测试与 metamorphic testing 补充可验证的一手文献，并逐条核对 StateFuzz 与已有方法的差异。

与只在固定任务和固定长度上报告准确率的评估范式相比，StateFuzz 关注同一行为探测在多个压力家族和上下文预算上的响应轨迹。其分析单位不是单个最终分数，而是由 signed margin、归一化 margin retention、failure probability 以及明确的缺失状态组成的压力表面。后续文献定位应重点区分能够生成长上下文样例的方法、能够检测行为不一致的方法，以及能够形成多维鲁棒性表面的方法，避免仅凭“长上下文测试”这一宽泛标签主张方法独特性。

与直接比较不同架构的排行榜式研究不同，StateFuzz 使用模型内归一化轨迹进行描述性对照。当前三个 checkpoint 在规模、训练数据、指令微调、随机种子和 token 容差上并不匹配，因此跨模型差异只能作为架构角色相关的候选模式，而不能构成架构因果证据。后续相关工作需要分别覆盖 pure SSM、Transformer 与 Hybrid 架构的评测研究，并明确哪些研究控制了这些混杂因素。

StateFuzz 还与软件测试中的 fuzzing 思路具有方法论联系：它通过系统扰动输入条件暴露行为响应，而不是修改模型权重。不过，本稿尚未基于外部文献验证这种联系对应的最近方法、术语边界或已有基准。正式版本应在保持当前实证 claim 不变的前提下完成文献检索，并将新增引用限定为背景和方法定位，不能用引用替代本仓库尚未获得的实验覆盖。
