# 引言

状态化序列模型需要在逐步处理输入的同时维持与任务相关的信息。当输入长度增加、无关内容插入或词汇形式发生变化时，模型的最终行为不仅取决于上下文长度，还可能受到压力结构与模型内部状态更新方式的共同影响。因此，记忆鲁棒性评估不应只回答模型在某一长度是否答对，还应刻画行为证据如何沿多个压力轴变化。

现有的单点评估容易把三个不同问题混在一起。第一，某个已测试点上的负 margin 是实际行为失败，而没有观测值可能只是预算不可达。第二，短上下文与长上下文之间的差异可能是单调退化，也可能是下降后恢复的非单调响应。第三，不同 checkpoint 的曲线差异可能来自架构，也可能来自规模、训练数据、微调方式、随机种子或 token 预算拟合误差。若不显式保存这些边界，跨模型比较很容易被误读为模型排名或架构因果证据。

StateFuzz 将记忆鲁棒性评价组织为可审计的压力表面。该框架首先按照预定义压力家族生成成对提示，然后通过相同候选集合进行行为探测，以方向一致的 signed margin 表示模型偏好，最后在模型、压力家族和上下文预算三个维度上汇总 margin retention、failure probability 与缺失状态。这个流程的目标不是宣称一个适用于所有模型的 failure detector，而是系统呈现已评估区域内的响应形状和证据缺口。

本文基于冻结的三 checkpoint 证据包构建实验叙事。Mamba-130M 与 Pythia-160M 提供历史 pure-SSM 和 pure-Attention 参考，Zamba2-1.2B-Instruct-v2 提供已测试的 Hybrid SSM+Attention checkpoint。结果表明，StateFuzz 能将这些异构证据统一为描述性压力表面；不同 checkpoint 与压力家族的模型内 margin 轨迹并非一致单调，而全部已评估 cohort 的 failure probability 均为零。本文据此主张 StateFuzz 能自动刻画架构角色相关、压力相关的记忆鲁棒性表面，但不把跨 checkpoint 差异解释为架构因果，也不对未获得 checkpoint 的 Mamba2 或现代 Attention 模型作泛化判断。
