# 摘要

固定 benchmark 分数或单一上下文长度可能掩盖只在特定压力条件下出现的远程记忆失败。本文提出 StateFuzz，一个将受控压力生成、反事实成对行为 margin、失败区域定位与可选状态干预连接起来的状态化序列模型评估框架。在冻结的 structured-repetition 协议中，StateFuzz 对 16 个 fresh seeds 定位到 Mamba-130M 的长上下文 failure regime：目标 1792 token、实际 1791 token 时，Mamba 失败 12/16，而配对的 Pythia-160M 参考失败 0/16，形成 12 个 Mamba-only discordant pairs，exact two-sided McNemar p=0.00048828125；lexically diverse negative control 未出现对应失败。随后，Mamba 循环状态干预显示，Round20 中 correct-memory state 恢复 8/8，wrong-memory state 恢复 0/8，matched-random state 恢复 1/8；Round21 fresh seeds 将三者复制为 8/8、0/8 和 0/8。因此，在结构化重复的远程记忆压力条件下，Mamba-130M 的循环状态内容会对远程记忆行为产生因果影响。迁移实验进一步覆盖多类压力、三类受控现实任务和 Hybrid Zamba2 checkpoint；其中后续 Round35/36 surface cohorts 在自身观测范围内没有 failure boundary，并呈现异质、部分非单调的 margin 轨迹。上述证据支持“发现—诊断—迁移”的框架主线，但不支持模型全局排名、架构因果、Mamba2 泛化或 Hybrid 内部路径归因。
